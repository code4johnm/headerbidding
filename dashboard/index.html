Header bidding

In-process auction. This page does not launch Firefox and does not visit a publisher site. Adapters are local functions. No bid request leaves this machine.

Bid request

Same fields as BidRequest. Price rule is first or second. Second price is the runner-up CPM plus one cent, and it never exceeds the winner.

Adapters

The demo set is appnexus 1.20, rubicon 1.80, ix timeout, and pubmatic no-bid. Each card is one local adapter: name, status, CPM, response time, currency, size, ad id, and message. Timeout and error raise inside the process. A bid slower than the timeout is dropped. Win and impression URLs are filled by the auction.
